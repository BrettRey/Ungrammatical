# Ross Sources For Syntactic Islands

Source file: `/Users/brettreynolds/Downloads/Elicit - Sources on Haj Ross and Syntactic Islands.csv`

Best use for the chapter: Ross should not appear merely as a name in the
Chomsky-to-Ross sequence. The useful character point is his scientific
style: he made abstract syntactic patterns visible through memorable
labels.

Strongest sources:

- Ross 1967, `Constraints on variables in syntax`: primary source. MIT
  DSpace record confirms the dissertation, Chomsky as advisor, and the
  1967 date. Direct PDF download is 403 from the command line, but the
  handle page is accessible: `http://hdl.handle.net/1721.1/15166`.
- MIT Linguistics / Whamit 2025 memorial: strongest source for Ross as a
  terminological stylist. It explicitly links Ross to the island term and
  to names such as pied-piping, sluicing, gapping, and heavy NP shift.
- Harris 2021: already in the bibliography. Useful for the Chomsky
  setup, especially the idea that Chomsky had begun looking for possible
  movements that natural languages did not exploit.

Useful framing:

- Chomsky is lineage, not character.
- Ross is character only if the chapter shows what kind of linguist he
  was: someone with an ear for names that made invisible syntax easier
  to see.
- Avoid making the opening a great-man discovery story. The accurate
  shape is: Chomsky noticed a problem; Ross showed the earlier account
  was inadequate, systematized the terrain, and named the terrain.
