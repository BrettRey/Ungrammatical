This book is typeset in \LaTeX{} and built with XeLaTeX. The main text
face is EB Garamond. Charis SIL is used where linguistics requires
broader phonetic and historical coverage, with Menlo for monospaced
material.

The page is set to a 7-by-10-inch trim. The cover uses a custom
five-stroke asterisk mark developed for the book, with separate front-cover
and wraparound production files.
